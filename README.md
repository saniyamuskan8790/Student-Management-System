# Student Management System (SQL)

The **Student Management System** is a simple SQL-based project designed to demonstrate the fundamentals of database management using **SQLite**. It manages student information, course details, and enrollment records through a structured relational database.

This project includes the creation of tables, insertion of sample data, and execution of basic SQL operations such as **SELECT**, **WHERE**, **UPDATE**, **DELETE**, and **ORDER BY**. It provides hands-on experience with organizing data, retrieving information, and managing records efficiently.

### Features

* Store student details
* Manage course information
* Record student enrollments
* Perform CRUD (Create, Read, Update, Delete) operations
* Filter and sort data using SQL queries

### Technologies Used

* SQL
* SQLite
* Visual Studio Code

This project helped me understand the basics of relational databases, table creation, data manipulation, and SQL query writing. It serves as a strong foundation for learning advanced database concepts and building larger database-driven applications.
